# Sound credits

The recordings the Meadow plays in a person's own garden (the sound button, top right). Generated from
`lib/sound/library.ts`: edit that file (by re-running the assets script), then write this one again; do not edit
it by hand.

Every recording is CC0, public domain or CC BY, and its licence was read on its own source page. Each was changed for
the garden, as CC BY asks us to say: Trimmed, levelled and faded for the garden; beds and calls mixed to mono.

Two sounds are not recordings at all: the **music box** (an endless piece in D, the party trailer's voice) and the
**soft noise** (warm brown noise) are generated in code on the listener's device, and have no file here.
